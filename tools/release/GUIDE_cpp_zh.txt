CloudRender 桌面（C++ 版）v0.1.0 使用说明
======================================================================

一、这是什么
CloudRender 把一台 Windows 电脑的桌面实时“搬”到浏览器里：远程电脑的画面
和声音传到网页，网页上的键盘、鼠标、触摸操作实时送回远程电脑。远程电脑
上不需要安装被控端软件，Windows 里运行的软件也不用改造。

本安装包是 C++ 版服务端，自带运行环境，目标电脑不需要安装 Python。

使用前请先阅读“五、使用限制”，特别是第 1 条网络直达要求。


二、运行环境
- 被控电脑：Windows 10 / 11（64 位，Intel/AMD）；不支持 32 位系统，
  ARM 版 Windows 未验证。
- 访问设备：能打开网页的电脑、平板或手机；推荐最新版 Chrome / Edge。
- 硬件：普通办公电脑即可；高分辨率、高帧率时更依赖 CPU / 显卡性能。
- 网络：访问设备必须能直接访问被控电脑的 IP 和端口（见“五、使用限制”）。


三、快速开始
1. 启动服务端
   把整个 cloudrender-desktop-cpp 文件夹放在本机任意位置（不要只复制 exe），
   双击其中的 start_server.cmd。
   弹出“用户账户控制”时选择“是”（管理员权限，锁屏后输入密码需要）。
   保持随后出现的黑色命令行窗口开启；关闭窗口即停止服务。

2. 打开页面
   被控电脑本机：浏览器访问 http://localhost:8081/
   同一局域网的其它设备：浏览器访问 http://被控电脑IP:8081/
   例：http://192.168.1.20:8081/
   首次启动时 Windows 防火墙会询问是否允许网络访问，请选择“允许”
   （至少勾选“专用网络”）。

3. 开始操作
   页面上的 Token 输入框默认已填 123456，与 start_server.cmd 里的默认口令
   一致，直接点击 Connect 即可。
   等待画面出现后，点击一次画面，键盘和鼠标就开始控制远程电脑。右上角
   显示实时帧率、码率、分辨率和会话时长。
   如果服务端改了口令，请先在 Token 框里填入新口令再点 Connect。


四、页面功能
- Token：访问口令输入框，默认 123456；连接成功后不可修改，需要换口令
  时先点 Disconnect。口令错误时页面会提示 Token rejected，并停止自动重连。
- Connect / Disconnect：建立或断开远程会话。
- Audio: Off / On：打开或关闭远程电脑的系统声音（不中断画面）。
- Lock：锁定远程电脑（等同在电脑上按 Win+L）。锁屏后直接在画面里输入
  Windows 密码即可解锁；非管理员启动时只能看到锁屏画面，无法输入。
- Fullscreen：让网页全屏（Esc 退出）。注意连接后 F11 会被发送到远程
  电脑，本地全屏请用这个按钮。
- Pointer lock：鼠标相对移动模式，适合 3D 游戏；需要打字时取消勾选。
- 触摸屏：单指点击=左键，单指拖动=拖拽，双指=滚轮，三指=右键。
- 中文输入法可以直接使用；点击画面后键盘输入直达远程电脑。


五、使用限制（请在部署前逐条确认）

1. 不能穿透网络，必须“直达”
   本产品不提供内网穿透或服务器中转。使用的前提是：打开浏览器的
   那台设备能够直接访问到被控电脑的 IP 地址和 8081 端口。
   - 同一局域网内通常可以直接使用。
   - 从互联网访问时，被控电脑必须有公网 IP，或者由网络管理员在路由器 /
     云服务器安全组上把被控电脑对外开放；只开放网页端口往往不够，音视频
     通道也要能通，否则会出现“页面能打开、画面连不上”。
   - 双方各自在内部网络、又没有公网入口时无法连接；请先自行打通网络
     （例如端口映射、VPN、专线），这不是本产品能代替的。
   - 本产品不是远程开机工具：被控电脑关机或休眠时无法连接。

2. 被控电脑必须开机、联网并保持登录
   - 关机、睡眠 / 休眠、断网、注销 Windows 用户、切换到其它用户，都会
     导致远程连接中断。
   - 可以锁屏（用页面上的 Lock 按钮），锁屏不影响远程连接。
   - 服务端是前台程序，不会开机自动启动，也不能在没人登录桌面的情况下
     后台运行；电脑重启后需要重新双击 start_server.cmd。
   - 关闭黑色命令行窗口就停止服务，远程将无法再连接。

3. 同一时间只能一个人使用
   - 默认只允许 1 个人同时连接，第二个人会被拒绝。
   - 从同一个 IP 地址重新连接时，会把之前的连接顶掉，旧页面会断开。

4. 锁屏功能需要管理员权限
   - 双击 start_server.cmd，并在“用户账户控制”弹窗选择“是”。
   - 普通权限启动仍可看画面、控鼠标键盘，但点 Lock 后只显示静止的锁屏
     画面，无法输入密码解锁。
   - Ctrl+Alt+Del 无法远程发送（Windows 不允许程序模拟），锁屏请用页面
     上的 Lock 按钮。

5. 系统安全界面可能无法远程操作
   - Windows 弹出的管理员授权（UAC）窗口等系统级安全界面，远程画面
     可能黑屏或没有反应，需要有人在本机操作。
   - 锁屏登录界面是支持的：用页面上的 Lock 锁定后，可以直接输入当前
     用户的密码解锁（需要管理员权限）。

6. 一个会话只看一个屏幕
   - 默认显示主显示器。多显示器电脑同一时间也只推送一个屏幕，其它屏幕
     看不到；需要看副屏时要在启动命令里指定显示器（见“六、高级选项”）。

7. 声音只有“电脑正在播放的声音”
   - Audio 开关传输的是被控电脑的系统混音，也就是扬声器里正在播放的
     声音；不采集麦克风，不能只传某一个软件的声音，也不能把浏览器端的
     声音传回被控电脑。
   - 浏览器页面必须未静音、系统音量已打开，才能听到声音。

8. 只传画面、声音和键鼠，不传文件
   - 不支持剪贴板互通（不能复制粘贴文字 / 图片到远程）。
   - 不支持文件上传 / 下载，也不能使用远程电脑上的 U 盘、打印机、
     摄像头等设备。

9. 操作会直接影响本机当前用户
   - 远程键鼠等同于坐在电脑前操作，会移动真实鼠标、输入真实按键。
   - 不适合多人同时使用同一台电脑；重要操作前请确认没有他人在使用。

10. 默认口令是 123456，必须修改
   - 为方便首次使用，默认连接口令是 123456，页面输入框也已预填。这个值
     是公开的，任何能打开 http://被控电脑IP:8081/ 的人只要输入 123456 就
     能操作这台电脑。
   - 放到办公网或公网前，必须改成自己的口令：编辑 start_server.cmd，把
     --token 123456 换成只有自己人知道的值；页面 Token 框同步填写新口令。
   - 口令只是第一道门，还应配合防火墙限制来源 IP；到公网使用建议加 VPN
     或 HTTPS 反向代理。
   - 建议只在可信网络中临时使用，用完关闭服务端窗口。

11. 画面和流畅度受机器、网络影响
   - 分辨率跟随被控电脑当前屏幕；网络带宽不足或延迟高时会降画质、卡顿、
     掉帧。
   - 没有独立显卡也能用，但高分辨率 / 高帧率时 CPU 占用较高，可能不流畅。
   - 部分受版权保护的视频或全屏运行的游戏画面可能黑屏、无法显示。

12. 浏览器与设备
   - 建议使用最新版 Chrome / Edge 桌面浏览器；IE 不支持，其它浏览器不
     保证所有功能都正常。
   - 手机 / 平板可以尝试用来看画面和触摸操作，但不适合精细操作或长
     时间办公。
   - 被控端只能是 Windows 电脑，不能控制 macOS / Linux / 手机系统。


六、高级启动选项（可选）
默认双击 start_server.cmd 即可，不需要修改。确有需要时，可在程序文件夹
打开命令行，用下面的方式启动：

  cloudrender-desktop-server-cpp.exe --port 8081 --fps 60 --bitrate 10000

  --port 8081          网页和连接端口，被占用时可改成其它值
  --fps 60             帧率上限（1-60），网络差可降到 30
  --bitrate 10000      目标码率（kbps），网络差可降到 3000-5000
  --monitor -1         显示哪块屏幕：-1=主屏，0=第一块屏，1=第二块屏……
                       （按显卡输出顺序，不一定等于系统显示编号，可多试）
  --token 你的口令      连接口令，默认 123456；浏览器页面 Token 框填写
                       同一口令（也可在地址后加 ?token=你的口令 预填）
  --token ""           传空字符串表示关闭口令校验（不推荐）
  --max-sessions 1     允许同时连接的人数，默认 1

修改端口后，访问地址里的 8081 也要相应修改。

八、常见问题
1. 页面打不开
   - 确认黑色命令行窗口还在运行、没有报错。
   - 确认地址和端口正确（默认 8081）。
   - 本机能打开、别的电脑打不开：检查 Windows 防火墙是否放行，以及两台
     电脑是否在同一网络、能否互相访问。
   - 若双击 start_server.cmd 没反应，检查杀毒软件是否拦截了本程序。

2. 能连上但画面黑屏 / 不动
   - 远程电脑是否锁屏、睡眠或显示器已关闭。
   - 是否被系统安全界面（UAC 等）挡住，需要本机操作。
   - 某些受保护视频 / 全屏运行的程序本身不允许捕获。

3. 没有声音
   - 确认页面上的按钮是 Audio: On。
   - 确认远程电脑正在播放声音、系统音量未静音。
   - 确认浏览器标签页没有被静音。

4. 点 Lock 后只有锁屏画面、输不了密码
   - 服务端没有以管理员身份运行。关闭窗口，重新双击 start_server.cmd，
     在“用户账户控制”弹窗选择“是”后再试。
   - 锁屏画面停在壁纸时，先点击一下画面或按一下 Shift，等密码框出现后
     再输入。

5. 提示“session limit reached”
   - 已经有人在连接这台电脑。请对方断开后重试。

6. 画面卡顿、模糊
   - 降低帧率 / 码率（--fps 30 --bitrate 5000），或改用有线网络。
   - 避免同时进行大文件下载、视频播放等占带宽的操作。

7. 端口被占用
   - 关闭占用 8081 端口的其它程序，或用 --port 换成其它端口。


九、安全提醒
远程控制等同于把电脑交给对方操作。默认口令 123456 是公开值，正式使用
前必须改成自己的口令；请勿把地址和口令发给不认识的人；不需要时关闭
服务端窗口；在公网使用还必须加网络访问限制（防火墙 / VPN / HTTPS 反代）。
因未改默认口令或未加防护导致的后果由使用者自行承担。
